Paste optional custom icon files here.

Recommended format:
- SVG for simple line/filled icons, or PNG/WebP for detailed icons.
- Transparent background.
- Square canvas such as 512x512.
- File names should be lowercase with underscores only.

If you want Android resource icons instead of asset icons, paste final files into:
app/src/main/res/drawable

Drawable resource file names must be lowercase with underscores only, for example:
ic_leg_raise.svg
ic_shoulder_stretch.svg
